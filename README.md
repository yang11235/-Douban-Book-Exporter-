# 豆瓣读书个人数据导出脚本 (Douban Book Exporter)

这是一个用于导出豆瓣读书“读过”列表数据的 Tampermonkey（油猴）脚本。它能帮助你将个人书单（包括书名、评分、评价、作者及出版信息）一键导出为 CSV 格式，方便进行阅读数据分析或备份。

**本脚本由 AI (Gemini) 生成代码，并经由本人亲测有效，完全可放心使用。**

## ✨ 主要功能
- **全量抓取：** 自动遍历所有分页，合并数据。
- **自定义导出：** 支持指定抓取书籍数量，灵活控制导出范围。
- **信息全面：** 包含书名、评分、评价（短评）、作者及出版详情。
- **数据本地化：** 数据通过 `localStorage` 临时存储，无需担心隐私上传，导出后自动清除缓存。
- **人性化操作：** 模拟人工点击频率，支持手动中断与进度显示。

## 🚀 安装指南
1. **安装插件：** 确保你的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 插件。
2. **安装脚本：** 点击这里 [chrome-extension://dhdgffkkebhmkfjojejmpbldmpobfkfo/ask.html?aid=b455e9b0-950b-4007-a0e8-974e4e21a8b9] 即可自动跳转安装。
3. **开始使用：** - 登录你的豆瓣个人主页，进入“读过”页面（链接通常为 `https://book.douban.com/people/你的ID/collect`）。
   - 页面右上角会出现一个【开始导出】按钮。
   - 点击按钮，输入你想导出的书籍数量，脚本将自动运行。

## 📋 注意事项
- **关于隐私：** 本脚本仅在本地浏览器执行，所有处理过程均不涉及远程服务器，保护你的账号隐私。
- **关于封控：** 脚本已内置随机延迟以模拟人工操作。但请注意，若频繁进行大规模抓取，仍可能触发豆瓣的验证码（CAPTCHA）。如果遇到，请手动完成验证，稍后再启动脚本即可。
- **用途说明：** 本脚本仅供个人备份和分析阅读偏好使用，请勿利用本脚本进行非法采集或大规模自动化攻击，请遵守 [豆瓣用户协议](https://www.douban.com/about/copyright)。
