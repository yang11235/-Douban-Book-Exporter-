# 豆瓣读书数据导出（Tampermonkey 脚本）

把豆瓣「读过」列表导出成一份干净的 CSV：**书名、我的评分、作者、出版社、我的短评**。

脚本在本地浏览器里运行，只读取你当前已登录的豆瓣页面，不联网上报、不上传任何数据。

**v8 由 DeepSeek-V4.1-Flash 重写，并已实测。**

当前版本 **v8.4**：在页面内翻页抓取（不跳页、不写本地存储），按 subject id 去重，抓完自动下载；遇到验证码、登录失效或网络错误会明确停下并说明原因，不会假报「导出完成」。

## 输出格式

| 列 | 说明 |
|---|---|
| 书名 | 豆瓣上的完整书名（保留副标题原样） |
| 我的评分 | 你打的分，1–5；没打分则留空 |
| 作者 | 原作者。多人合著用「、」连接，已剔除译者 |
| 出版社 | 出版社名称 |
| 我的短评 | 你写的短评全文；没写则留空 |

带 UTF-8 BOM、CRLF 换行，Excel / WPS 双击打开不乱码。

## 安装

1. 浏览器装好 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点这里安装脚本：
   [安装 douban-exporter.user.js](https://www.tampermonkey.net/script_installation.php#url=https%3A%2F%2Fgithub.com%2Fyang11235%2F-Douban-Book-Exporter-%2Fraw%2Frefs%2Fheads%2Fmain%2Fdouban-exporter.user.js)
3. 打开你的读过页 `https://book.douban.com/people/你的ID/collect`，右上角会出现面板。

## 使用

点「开始导出」→ 输入数量（留空 = 全部）→ 等它自己翻页 → **抓完直接下载，不用再点第二次**。

- 抓取中按钮会变成「中止」。
- 中途点中止、或撞上验证码 / 网络错误时，按钮会就地变成「保存已抓 N 本」，点一下把已有数据存下来，不会白跑。
- 翻页间隔 1.5–3 秒随机，1000 本大约两分钟。

## 注意事项

- 只在本地运行，用浏览器自带的登录态请求豆瓣页面，不向第三方服务器发送任何数据。
- 豆瓣有反爬策略：撞到验证码时请手动完成验证再重跑。
- 本脚本仅供个人备份和分析自己的阅读记录，请勿用于批量采集。
